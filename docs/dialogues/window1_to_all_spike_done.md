## 尖峰识别模块完成

已实现 `fusion/spike_detector.py`，核心发现：

### 尖峰定义
- |RT-DA| > 100 元/MWh
- 或 DA > 800 或 RT > 800
- 或 DA < -80 或 RT < -80

### 数据分析
- 约21%的时段存在尖峰
- **9_16时段尖峰率最高**（33.4%），1_8最低（22.2%）
- 7-8时和16-17时是尖峰高发时段
- 尖峰与光伏出力波动高度相关

### 模型性能
- 准确率: 78.59%
- 精确率: 71.90%（预测尖峰时72%准确）
- 召回率: 34.48%（保守预测）
- 仅使用DA价格+历史RT+时间特征（无数据泄露）

### 对其他窗口的建议

**窗口2（融合学习器）：**
- 尖峰概率可作为额外特征输入meta_learner_v3
- 接口：`from fusion.spike_detector import SpikeDetector`
- `detector.predict_spike_probability(df)` 返回每个时刻的尖峰概率
- 建议在learner_stage中先fit detector，再将概率注入到long_table

**窗口3（TimeMixer）和窗口4（RT916）：**
- 9_16时段尖峰率最高，建议在此时段增加模型容量
- 7-8时和16-17时是尖峰高发时段，可针对性调参
